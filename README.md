# Генератор коммерческих предложений (КП)

Одностраничное веб-приложение для создания коммерческих предложений за пару минут. Заполняешь данные компании и клиента, добавляешь позиции — получаешь готовое КП в PDF.

**[Открыть приложение →](https://artayvazyana-ux.github.io/kp-generator/)**

## Возможности

- **Данные компании** — название, телефон, e-mail, реквизиты
- **Данные клиента** — кому отправляется КП
- **Таблица позиций** — добавление/удаление строк, автоподсчёт суммы
- **Итого** — автоматический расчёт общей суммы
- **Условия КП** — срок действия (выбор даты через календарь), условия оплаты, примечания
- **Предпросмотр** — отображение КП в реальном времени
- **Экспорт в PDF** — скачивание готового КП в формате PDF (A4)
- **Кастомный календарь** — выбор даты в стиле приложения
- **Очистка формы** — сброс всех полей одним кликом

## Технологии

- **HTML5** — структура
- **CSS3** — стили (тёмная тема, адаптивная вёрстка)
- **Vanilla JavaScript** — логика без фреймворков
- **html2pdf.js** — генерация PDF
- **Google Fonts (Inter)** — типографика
